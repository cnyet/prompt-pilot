# 15 — 真实模型的真流式与用量透传

**What to build:** 配置 Key 后，用户看到的是逐字流出的内容，而不是等十几秒后一次性刷出。用量与思维链通过事件流到达界面：成本可见，思考过程可折叠查看，且绝不混进提示词正文。

**Blocked by:** 05 — 接上火山方舟

**Status:** ready-for-agent

- [ ] 有 Key 时首字延迟 < 2s（当前实现要等结构化输出全部完成，首字等于全长）

- [ ] SSE 新增 `usage` 与 `reasoning` 事件，并同步更新协议文档

- [ ] 思维链收进可折叠的「思考」区，正文不含任何思考内容
