# 01 — 离线生成打通到页面

**What to build:** 用户在空态输入一句话并回车，服务端用确定性模板填出八字段结构，内容通过 SSE 逐字段出现在中栏。生成过程可随时停止，结果可一键复制为 Markdown。全程不依赖任何模型 API。

**Blocked by:** None. Can start immediately.

**Status:** ready-for-agent

- [ ] 输入一句话后 20 秒内看到完整的八字段结构，且未配置任何 API Key
- [ ] 字段按顺序逐个出现，当前字段有可见插入符
- [ ] 点停止后已生成字段保持可编辑，未生成字段显示"未生成"并可单独重试
- [ ] 复制出的 Markdown 能直接粘进对话窗口使用
- [ ] 服务端事件顺序满足 stage 包裹 field 包裹 delta，并有测试断言
- [ ] 生成中断网时给出明确错误，不静默卡死
