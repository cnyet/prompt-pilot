# 07 — 错误分类与重试边界

**What to build:** 失败时用户看到的是具体原因，不是"请求失败"。只有限流与临时故障自动重试，欠费、模型未开通、参数错误立即给出处理指引，不做无意义重试。

**Blocked by:** 05 — 接上火山方舟

**Status:** ready-for-agent

- [ ] 限流与 5xx 按指数退避加抖动重试，最多三次
- [ ] 欠费、未开通、参数错误、内容安全四类不重试，各有专属文案
- [ ] 鉴权失败提示检查密钥，并指出是哪个环境变量
- [ ] 每次重试都记录在调用账本里
- [ ] 错误分类有单测，覆盖可重试与不可重试两侧
