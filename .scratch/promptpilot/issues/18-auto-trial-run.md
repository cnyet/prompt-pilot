# 18 — 生成结束后自动试运行

**What to build:** 变量有默认值时，生成完成后立即在结果上方自动跑一次试运行，把真实输出摆在提示词结构之前。用户不用先点「试运行」才知道这份提示词能不能用。

**Blocked by:** 11 — 试运行：变量与真实输出

**Status:** ready-for-agent

- [ ] 生成完成且变量有默认值时，自动触发一次试运行，无需用户点击
- [ ] 自动运行失败或不可用时不打断主流程，只在试运行区显示原因
- [ ] 用户手动点过「停止」或「重新开始」后，本轮不再自动触发
- [ ] 自动触发只发生一次，不因重渲染或撤销反复运行
- [ ] 有测试断言触发条件与去重

## Comments

### 2026-11-10 Lead 复核 11 时发现

`DESIGN.md` 4.1 写的是「变量有默认值时，生成结束后立即在中栏上方跑一次」，但 11 交付的是手动点击，agent 也在报告里主动标注了「没有做设计稿里的生成结束自动试运行」。

这不是实现失误，是工单 11 的验收标准里没有这一条（当时只写了「运行后流式打印」）。产品主路径的设计是「真实输出优先展示，结构退到后面」，没有自动运行这一步，这个设计就落不了地。

评估过放进工单 14（收尾），但 14 已经背着空态、错误态、键盘、响应式、E2E 五件事，再塞一个功能项会让收尾变成大杂烩。单独开票更清楚。
