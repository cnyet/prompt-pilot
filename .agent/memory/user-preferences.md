# User Preferences

## Communication
- 中文回复。
- 偏好行动优先：说「继续」即按提议的下一步执行，不要反复确认。
- 要求区分「已完成」与「已验证」，不接受把未验证当成完成。

## Coding Style
- 零依赖优先；新增依赖要给理由。
- 未知值用 null，不用 0 或哨兵值。
- 测试要盯住它在断言的行为，不要把偶然的字符数写死。

## Workflow
- 大改动先给计划，分批执行，批间可停下来看截图。
- 自测证据要真实：截图、对比度计算、测试结果，不靠口头描述。
- 文档与实现同步；文档里承诺的功能必须真的能用。

## Project Conventions
- 界面中文；禁感叹号与 em dash。
- 视觉：暖色纸感、衬线大标题、粉彩分区、无渐变无阴影。
