# PromptPilot v3 Phase 3 提示词库 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `/library` 从 v2 版本工作区替换为 v3 结果优先提示词库：可搜索筛选的记录列表、行内收藏/评分/重命名、详情抽屉（结果、迭代时间线、任意两轮对比、继续优化、检查、复制导出、存模板、删除）。

**Architecture:** 服务端页面只计算优化模型可用性并渲染客户端根组件。列表状态集中在 `LibraryV3`，查询与格式化是纯函数；详情抽屉用原生 `<dialog>`，焦点陷阱与 Esc 由浏览器提供。继续优化与修复复用 `usePromptStream`、`IterationCompare`、`ContinueBar`、`CheckPanel`、`SaveTemplateForm`，不新建第二套流式实现。

**Tech Stack:** Next.js 16 App Router、React 19、TypeScript strict、Tailwind v4、vitest 5（node 环境）。

**Spec:** `PRODUCT.md` FR-6、`DESIGN.md` Library Record Row / Detail Drawer / Empty State、`docs/ROADMAP-V3.md` Phase 3（V3-30 到 V3-33）、`CONTEXT.md` 记录与迭代词表。

## Global Constraints

- 包管理器只用 pnpm 10.14.0；定向测试用 `pnpm exec vitest run <path>`，不要用 `pnpm test -- <path>`。
- 测试只用 `data/test.db`，绝不读写 `data/app.db`；测试环境由 `tests/global-setup.ts` 与 `tests/setup-env.ts` 建立。
- 不新增依赖。原生 `<dialog>` 提供焦点陷阱，不引 Dialog 库。
- 所有界面文案进 `lib/i18n/zh.ts`，组件内不写中文字面量；键名稳定。
- 禁止感叹号、emoji、em dash（`—` 只用于未知值）。未知模型与费用显示「—」；未评分显示「未评分」；不写 0 代替未知。
- 设计：结果面是最亮的纸；单屏 primary 最多 1 个；金色不超过 10%；同屏 glow 最多 2 个；中文最小 12px；数字用 `tabular-nums`；正文 68ch；遮罩用 `rgba(26,15,10,.55)`，禁止背景模糊。
- 新代码不 import v2 引擎模块或 `lib/engine/schema.ts`；`lib/llm/types.ts` 冻结。
- 不记录提示词正文到日志；不新增密钥或配置值。
- 禁止 `git add -A` / `git add .`；不触碰无关的 `.agent/memory/handoff-*` 文件。

## Review Focus

1. **搜索与筛选竞态**：快速改搜索词或筛选时，旧请求的响应不得覆盖新请求的结果。
2. **空态分流**：完全没有记录与筛选后没有匹配是两种空态，动作分别是去工作台与清除筛选。
3. **行内评分键盘**：方向键调整评分时焦点保持在当前星，PATCH 在途不原生禁用控件。
4. **删除与流式并发**：继续优化或修复进行中不得删除记录；删除需二次确认，删除后列表与抽屉同时消失。
5. **长文本与缺失元数据**：120 字标题、80 字摘要、代理对截断；模型与费用未知显示「—」。
