**Goal:** 落地 v3 Phase 1 的第一批改动：三个新 Prisma 模型（PromptRecord / PromptIteration / Template）、LlmCall 关联列、settings 的 modelOptimize 与预算键、registry 的 optimize 角色。

**Architecture:** 只增不删：三张新表与 LlmCall 三个可空列追加进 `prisma/schema.prisma`，旧模型原样保留（Phase 6 再删）。设置沿用 `AppSetting` key/value 表；预算走独立 key `budget.monthlyCny`，未设置为空字符串。registry 以 `optimize` 角色新增模型槽位，未单独配置时复用生成模型（FR-8.3）。`lib/llm/types.ts` 冻结不碰，Batch A 不引入 stage 相关代码。

**Tech Stack:** Prisma + SQLite（`db push`，无 migrations 目录）、TypeScript、vitest（`tests/global-setup.ts` 隔离 `data/test.db`）。

**Spec:** `docs/ROADMAP-V3.md` §2.1（数据模型 verbatim）、§2.2（幂等两层）、§3 Phase 1；`PRODUCT.md` FR-8.3 / FR-9.5 / FR-9.6；设计简报 `docs/shape-studio-v3.md`。

## Global Constraints

- 旧表只增不删；`pnpm exec prisma db push` 前必须先备份 `data/app.db`。
- 用量与费用未知为 null，不写 0；`cachedHit` 用 `Boolean?`，未知为 null，不给默认值。
- `PromptIteration.requestId @unique`；`@@unique([recordId, seq])`。
- 密钥永不落 registry/settings 的非密钥字段；设置只回报末四位（沿用 `maskKey`）。
- 测试绝不读写 `data/app.db`，走 `tests/global-setup.ts` 的 `data/test.db`。
- 包管理器 pnpm；本项目无 lint 脚本。
- 不修改 `lib/llm/types.ts`（冻结）与 `lib/engine/schema.ts`（冻结至 Phase 1 新模型落地，Batch A 不动它）。
- 文案禁感叹号、em dash、emoji。

## Review Focus

1. **备份缺失即 push**：`db push` 对 `data/app.db` 有写行为，执行前必须存在当次会话新备份；验证 = 任务 1 步骤 1 的备份命令输出。
2. **cachedHit 带默认值**：若写成 `Boolean @default(false)` 会把「未知」伪造成「未命中」，违反未知为 null 契约；验证 = schema 中该字段为 `Boolean?` 且无 `@default`，tests/integration/schema-v3.test.ts 断言可写入 null。
3. **requestId 唯一约束缺位**：幂等第二层靠它，漏了会双击产生两条迭代；验证 = tests/integration/schema-v3.test.ts 断言重复 requestId 写入被拒。
4. **预算语义三态**：未设置必须读出 null（显示「未设置」），不是 0；非法输入（负数、非数字）必须拒绝保存；验证 = tests/unit/settings-optimize-budget.test.ts 三条断言。
5. **优化模型回退**：未单独配置时优化必须复用生成模型（FR-8.3），包括设置页视图的 source 链与 registry 的槽位解析；验证 = registry-optimize.test.ts 与 settings 测试的回退断言。

```prisma
// v3 提示词记录：一次完整处理的落库结果（ROADMAP-V3 §2.1）
model PromptRecord {
  id             String   @id @default(cuid())
  title          String
  mode           String // generate | optimize
  targetType     String   @default("text") // text | image | video
  sourceInput    String // 生成需求或原始提示词
  latestOutput   String   @default("")
  status         String   @default("running") // running | completed | canceled | failed
  favorite       Boolean  @default(false)
  rating         Int? // 1..5，未评分为 null
  modelId        String?
  iterationCount Int      @default(0)
  tokensIn       Int?
  tokensOut      Int?
  costCny        Float?
  copiedAt       DateTime? // 最近一次复制时间；一次通过率埋点
  originTemplateId String? // 从模板「用它开始」进入时写入；模板使用率埋点
  createdAt      DateTime @default(now())
  updatedAt      DateTime @updatedAt
  iterations     PromptIteration[]

  @@index([status, updatedAt])
  @@index([favorite, updatedAt])
  @@index([mode, updatedAt])
}

// v3 迭代：同一条记录内的每一轮处理（ROADMAP-V3 §2.1）
model PromptIteration {
  id          String   @id @default(cuid())
  recordId    String
  seq         Int
  kind        String // generate | optimize | repair
  instruction String?
  output      String   @default("")
  notesJson   String   @default("[]")
  modelId     String?
  tokensIn    Int?
  tokensOut   Int?
  costCny     Float?
  latencyMs   Int?
  status      String   @default("running")
  requestId   String?  @unique
  createdAt   DateTime @default(now())
  record      PromptRecord @relation(fields: [recordId], references: [id], onDelete: Cascade)

  @@unique([recordId, seq])
  @@index([recordId, createdAt])
}

// v3 模板：文本 / 图片 / 视频三类预置与自定义模板（ROADMAP-V3 §2.1）
model Template {
  id           String   @id @default(cuid())
  slug         String?  @unique
  category     String // text | image | video
  style        String
  title        String
  description  String
  body         String
  mode         String   @default("optimize") // generate | optimize
  exampleInput String?
  coverKind    String   @default("programmatic")
  featured     Boolean  @default(false)
  builtin      Boolean  @default(false)
  createdAt    DateTime @default(now())
  updatedAt    DateTime @updatedAt

  @@index([category, style])
}
```

```ts
/** 月度预算（人民币）；未设置为空字符串，读取为 null（FR-9.5/9.6）。 */
export const BUDGET_SETTING_KEY = 'budget.monthlyCny'

export async function getBudgetSetting(): Promise<number | null> {
  const prisma = getPrisma()
  if (!prisma) {
    return null
  }
  try {
    const row = await prisma.appSetting.findUnique({ where: { key: BUDGET_SETTING_KEY } })
    if (!row || row.value.trim().length === 0) {
      return null
    }
    const value = Number(row.value)
    return Number.isFinite(value) && value > 0 ? value : null
  } catch (error) {
    console.warn('[settings] 读取预算失败：', error)
    return null
  }
}

export async function saveBudgetSetting(value: number | null): Promise<void> {
  const prisma = getPrisma()
  if (!prisma) {
    throw new SettingsError('NO_DATABASE', 503, '数据库不可用，设置暂时无法保存。检查 DATABASE_URL 是否配置。')
  }
  if (value !== null && (!Number.isFinite(value) || value <= 0)) {
    throw new SettingsError('INVALID_BUDGET', 400, '预算必须是大于 0 的金额。')
  }
  try {
    if (value === null) {
      await prisma.appSetting.deleteMany({ where: { key: BUDGET_SETTING_KEY } })
    } else {
      await prisma.appSetting.upsert({
        where: { key: BUDGET_SETTING_KEY },
        create: { key: BUDGET_SETTING_KEY, value: String(value) },
        update: { value: String(value) },
      })
    }
    invalidateCache()
  } catch (error) {
    console.warn('[settings] 预算保存失败：', error)
    throw new SettingsError('WRITE_FAILED', 503, '设置写入失败，请稍后重试。')
  }
}
```
