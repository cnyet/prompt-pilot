# ADR 0004：编辑部 bento 构图重构

日期：2026-11-10
状态：已接受

## 背景

用户对现界面的五页整体不满意，要求推倒重来（视觉、交互、布局、配色、页面内容）。参考物为 OpenDesign 的 Orbit 综合简报（`example-orbit-general`，下称 Orbit）。

拆解 Orbit 的画布令牌后确认：其配色与现项目**同源**（页面底 `#FAF7F2` ≈ `--bg`，墨色 `#1A1816` ≈ `--text`，accent `#D86A47` 即现赤陶主色，同样无阴影无渐变、1px hairline）。因此重构变量**不是配色**，而是构图。

## 决策

五页全面重构为「编辑部 bento」构图，保留暖纸色系与全部功能模型：

1. **字段异构化**：八个字段不再是同一种 DocSection，按数据形态各选 UI 形态（objective 巨型衬线陈述、audience 头像组、constraints 做/不做双栏、variables 等宽表格等）。映射表见重构计划。
2. **数字主角**：KPI 与统计用巨型衬线数字（64-96px）。拉丁数字引入 Cormorant webfont 子集作为 `--font-numeral`；中文标题维持系统衬线栈，不违反 ADR 0001 的「不引中文展示字体」。
3. **流程时间轴**：工作台顶部横向阶段轴（需求→生成→试运行→评估→优化），当前阶段赤陶块 + now 脉冲点，承担全局状态表达。
4. **诊断 dock**：诊断从右栏常驻改为底部可折叠 dock（⌘J），主区收回 320px 宽度。有 error 时时间轴徽标提示。
5. **导航降权**：侧栏收窄为图标态（64px），全局 hero 收进单行。

不变量：八字段 Schema、假设 chip、16 条诊断规则、试运行、v0 基线盲评、版本链、导出、快捷键体系（⌘K/⌘Enter/⌘S/Esc/`\`/⌥1-3）。功能模型零改动，本 ADR 只约束表现层。

## 依据

- 用户审美锚点：Uber 纯黑白、Linear 密度（工具层保留）；但对 Orbit 的实际认同点经拆解为构图而非色系。
- Orbit 的模块异构原则（每模块按数据形态选 UI，拒绝同质卡）直接映射到八字段。
- 浅色为主的场景句不变（白天办公室、与文档并排），故色系保留。

## 后果

- 正面：字段页获得版式差异与信息密度；证据类数字（胜率、通过率）成为视觉主角；主区宽度增加。
- 负面：诊断即时性下降一档（从常驻变 dock），以 ⌘J 与时间轴徽标补偿；Cormorant 子集新增约 2KB 网络字体。
- 兼容：`--font-numeral` 令牌新增，其余令牌不动；实施按 R0-R5 分阶段，每阶段独立验收，全程 466 测试与对比度脚本为回归底线。
