# ADR 0006：烛光羊皮纸视觉方向

日期：2026-11-11
状态：已接受

## 背景

用户对旧 `DESIGN.md` 的暖纸、赤陶与编辑部 bento 叙事不满意，要求用 ui-ux-pro-max 重做设计系统。过程中比较过瑞士黑白方案，用户随后提供 `~/Downloads/questui-DESIGN.md`（QuestUI，奇幻 RPG 风格），并明确选择「改用 QuestUI 的奇幻视觉」。

QuestUI 原稿不能直接落地：

- 只有深色方案，没有浅色变体。
- 字体为 Cinzel / Spectral / Fira Code，无中文字形。
- 11px 大写 chip、纯装饰 glow、深红与紫色直接做文字色。
- 实测 `#991B1B` 文字在 `#2C1A10` 上仅 2.00:1，`#581C87` 仅 1.73:1，白字压在 `#CA8A04` 上仅 2.94:1。

## 决策

采用 QuestUI 的视觉语法，改写为 PromptPilot 的「烛光羊皮纸」系统：

1. **双主题材质**：深色为烛光地下室（深棕分层、金色主操作、羊皮纸文字），浅色为羊皮纸日光变体。两套主题都完整可用，浅色不是深色反相。
2. **中文排版**：页面标题、大陈述句与 KPI 数字用系统宋体栈；正文、控件用系统无衬线；变量与数字用系统等宽。零网络字体，不加载 Cinzel / Spectral / Fira Code。
3. **金色预算**：金色只给主操作、当前步骤、关键数字与选中态；同一屏 primary 按钮 1 个，发光元素不超过 2 个。
4. **对比度修正**：深红与紫色只做底色或分区底，文字改用通过 4.5:1 的语义色；金色主按钮用深色 `--on-accent` 文字。全部令牌组合已用 WCAG 脚本实测。
5. **装饰克制**：保留 2 到 8px 小圆角、1px 细边、顶部 2px 金色描边、分层表面与 active glow；禁止彩色渐变、玻璃拟态、霓虹描边、emoji 图标与常驻 glow。
6. **构图沿用 ADR-0004**：八字段异构、流程时间轴、诊断 dock、64px 图标轨继续有效，只替换材质、色彩、字体与组件规格。

不变量不变：八字段 Schema、假设 chip、16 条诊断、试运行、v0 基线盲评、版本链、导出、快捷键、离线可作业、密钥安全、修复不覆盖手改。

## 依据

- 用户明确选择奇幻视觉，并接受羊皮纸浅色变体与系统宋体中文字体。
- 抽样对比确认 QuestUI 的深棕分层、金色主操作与顶部描边能建立比旧暖纸系统更强的层级。
- 直接照搬会在中文、浅色、可访问性与组件覆盖上失败，因此采用「借语法、重写令牌」的策略。

## 后果

- `DESIGN.md` 整体重写；`docs/design-preview/questui-workbench.html` 提供工作台静态样张，截图存 `docs/assets/design-v2/`。
- ADR-0001 的视觉结论与 ADR-0004 的色彩/字体结论被本 ADR 取代；ADR-0002（CSS 动效）、ADR-0003（评估判定输出）、ADR-0005（shadcn 工程模式）继续有效。
- 迁移分 Q0 到 Q5：Q0 只交付文档与样张，不改应用代码；Q1 令牌与基座组件，Q2 工作台，Q3 库与评估，Q4 模板、设置与全局 chrome，Q5 响应式、双主题与 a11y。
- 风险：奇幻材质可能压过工具密度。缓解手段是金色预算、glow 上限、正文无衬线与 12px 最小字号；每阶段用 1440 / 1024 / 390 截图复核。
- 回滚：Q0 无代码改动，可直接回退文档；Q1 之后按阶段独立 diff，令牌改动保留旧值备份与对比度脚本结果。
