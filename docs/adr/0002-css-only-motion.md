# ADR-0002：动效只用 CSS，且限两类

- 状态：已采纳
- 日期：2026-11-10

## 背景

页面"死"的观感主要来自内容出现时毫无提示：字段流式写完直接出现，面板展开瞬间到位。可选方案是引入动效库（Motion / GSAP）做编排，或用纯 CSS 过渡。

## 决定

不引入动效库。只做两类动效：

1. **内容出现**（`rise`）：字段、列表项、空态首次渲染时 `opacity 0 → 1` 并上移 6px，时长 120ms。
2. **容器展开**（`reveal`）：导出浮层、诊断分组、折叠区，`opacity` + `translateY(-4px)`，时长 180ms。

硬性限制：

- 只动 `opacity` 与 `transform`，不动 `width` / `height` / `top`。
- `prefers-reduced-motion: reduce` 下时长归零，不做任何位移。
- 同一屏内同类动效只出现一次，不给每个元素加不同延迟。

## 影响

- 首屏不引入额外 JS，CLS 不变。
- 复杂编排（滚动触发、路径动画）在本项目内不可用；如果后续需要，再单独立项评估。

## 备选与放弃理由

- **GSAP**：能力强，但为两个 100ms 级别的过渡引入几十 KB 运行时，性价比不成立。
- **完全不做动效**：内容出现缺少空间连续性，是当前"粗糙感"的直接来源之一。
