# ADR-0001：视觉方向定为「编辑刊物感」，而非"更专业的工具感"

- 状态：视觉结论已被 ADR-0006 取代；动效与工程约束仍有效
- 日期：2026-11-10

## 背景

界面经过四轮改造后仍被评价为"过于简单、不够好看"。候选方向有三条：刊物感（暖纸底、衬线大标题、大留白、粉彩分区）、工具感（收起衬线、更高密度、更强状态色）、两者混合。

当时页面已经换过暖色纸感主题，但只换到一半：标题是衬线了，正文仍是 12-13px 密排，留白只有参考稿的一半。

## 决定

继续往刊物感走到底，不换方向。

三条具体约束：

1. 页面级 `h1` 使用中文衬线栈，字号提升到 40-44px，字重 400。
2. 正文仍用无衬线，但行高提到 1.7，段落间距与字段间距整体放大。
3. 粉彩分区只做背景，不做文字色，避免与语义色抢。

## 影响

- 单屏信息量会下降，需要靠"分组与层级"补，不能靠压缩字号。
- 深色模式必须同步调整，暖色令牌在深色下要重新校准对比度。
- 与 `DESIGN.md` 的 12 条禁令一致（不用纯黑白、不用渐变），不需要改禁令。

## 备选与放弃理由

- **工具感**：更像 Linear，但在一个只有三栏、五页的产品里，高密度会让页面显得更空——没有足够数据填满密集表格。
- **混合**：两套语言要维护两套间距与字号规则，收益不足以抵消成本。
