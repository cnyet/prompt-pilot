# 编辑部 bento 重构计划

不是再调一轮颜色。前四轮（B1-B7、P1-P4）做的是参数层与骨架层，这次动**构图层**：字段长什么样、数字当不当主角、流程怎么画出来。方向决策记录见 `docs/adr/0004-editorial-bento-redesign.md`。

参考物：OpenDesign Orbit 综合简报（`example-orbit-general`）。其色系与本项目同源（暖纸底 `#FAF7F2`、墨 `#1A1816`、赤陶 `#D86A47`，无阴影无渐变），因此**配色基本不动，构图全面替换**。

## 一、不变量（全程不许碰）

- 八字段 Schema、假设 chip 点击局部重算、16 条本地诊断规则、试运行、v0 基线盲评胜率、版本链、六格式导出。
- 快捷键：⌘K、⌘Enter、⌘S、Esc、`\` 折叠侧栏、⌥1-3 三视图。
- 文案纪律：禁感叹号、禁 em dash、禁「强大/智能」空词、数字等宽。
- 密钥安全、离线可作业、修复不覆盖手改。
- 对比度 ≥4.5:1 双主题；466 测试全绿为回归底线。

## 二、令牌与基座（R0）

新增令牌（`app/globals.css` 两套主题同时加）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--font-numeral` | Cormorant 600 拉丁数字子集 + Georgia 回退 | KPI 数字、巨型序号、胜率 |
| `--numeral-hero` | 64px / 行高 1.05 | KPI 条 |
| `--numeral-mega` | 96px / 行高 1.0 | 评估不满足计数、Top 3 序号 |
| `--tint-do` / `--tint-dont` | 绿/红浅底 | constraints 双栏 |

数字一律墨色衬线，**不做彩色数字**；唯一例外：评估「不满足」计数用 danger 衬线大数字（对应 Orbit 的 Sentry 红大数字场景）。

基座改动：

- bento 网格原语：`.bento-grid`（CSS grid，卡片可跨行跨列，`grid-auto-flow: dense`）。
- hairline 收严：分隔一律 1px `--border`，容器不再叠双层边框。
- 补齐状态矩阵（DESIGN.md 第五节）中缺状态的组件。
- Cormorant 用 `next/font` 数字子集加载（约 2KB），失败回退 Georgia 不阻塞。

## 三、全局 chrome

顶栏从 48px 通用栏改为 Orbit 式单行 hero：

- 左：当前页名（中文系统衬线，页面级 h1）+ 日期 + 模型状态（在线/离线模板，caption 级）。
- 右：⌘K 搜索入口 + 主题切换。
- 侧栏 240px → 64px 图标态（悬停展开短标签），导航降权，内容区拿回宽度。

## 四、工作台（R1）

骨架从三栏（180/1fr/320）改为：

```
hero 单行
流程时间轴（全宽，约 100px）
字段 bento 网格（全宽，数据富字段跨两列）
诊断 dock（底部可折叠，⌘J）
```

### 流程时间轴

需求 → 生成 → 试运行 → 评估 → 优化。已过阶段墨色块，当前阶段赤陶块 + 脉冲 now 点（`prefers-reduced-motion` 下点静止），未到阶段 hairline 空块。诊断 error 数进当前阶段徽标。

### 字段形态映射（核心）

| 字段 | 形态 | 规格 |
|---|---|---|
| 01 objective | 巨型衬线任务陈述 | h2 级衬线一句话，跨两列，页面第二主角 |
| 02 audience | 头像组 + 描述行 | 圆形头像组（Orbit avatar stack）+ 人群一句话 |
| 03 context | 摘录块 | `--surface-inset` 底，两行摘要，可展开全文 |
| 04 constraints | 做/不做双栏 | `--tint-do` / `--tint-dont` 浅底对照，边界缺口一眼可见 |
| 05 variables | 等宽表格 | 变量名/类型/默认值三列，`{{}}` 高亮 |
| 06 examples | 编号样本列表 | 衬线序号 + 输入→输出对 |
| 07 successCriteria | 可勾选判定列表 | 评估时直接变成 verdict 行 |
| 08 output format | 骨架预览 | 目标格式灰字骨架示意 |

字段卡点击聚焦进入编辑，操作条（重算/加长/缩短/更具体/重新生成）**聚焦态常驻**，替代悬停显形。AI 内容与手改内容的标记方式保留。

### 诊断 dock

底部可折叠，`⌘J` 开关。error/warn/info 分组，每组一块浅底；「结论/原因/建议」三级结构保留；修复与忽略改为常驻文字按钮（dock 里不再依赖悬停）。

### 其余保留

三视图（结构化/渲染文本/JSON，⌥1-3）、假设 chip 行（不套外框）、试运行区（变量表单 + 输出 + 耗时 token）均重排进 bento 网格，行为不变。

## 五、提示词库（R2）

卡片网格 → **行式 bento 列表**：

- 每行：标题、描述一行（无描述取最新版本正文首行 90 字内）、标签 chips、**衬线数字列**（版本数、v0 胜率）。
- 胜率无数据显 `—`（等宽），不显示 0%。
- 行点击开右侧详情抽屉（版本时间线 + 基于某版本继续编辑），行为不变。
- 搜索与排序在列表上方一行收拢。

## 六、评估（R3）

- 顶部创建区重排（选提示词、按行填样本最多 5 条、开始评估），行为不变。
- 结果页：**KPI 条**（通过率 / v0 胜率 / 已判定样本数，`--numeral-hero` 衬线数字，无数据 `—`）。
- 「不满足」计数用 danger 衬线大数字（`--numeral-mega`），一眼看到质量缺口。
- 样本对照双栏（当前版本 vs v0），判定按样本分组、每条标准一个 verdict 行（满足/部分满足/不满足）。
- 无评委模型：数值留 `—` 标「待人工判定」（ADR 0003 规则不变）。

## 七、模板与设置（R4）

- 模板：两列卡片改异构网格（图标块大小随场景类型变化），动作「用它开始」。
- 设置：锚点导航 + 分区保留；模型区状态条改单行 hero 式；成本区统计块换 `--numeral-hero` 衬线数字；密钥安全行为不变（AC-11）。

## 八、深色与响应式（R5）

- 深色校准：暖炭灰底不变，衬线数字颜色跟随 `--text`，赤陶 accent 提亮规则不变。
- 响应式：1440 基准；1280 起 bento 网格降为单列堆叠、时间轴保留；<1024 退单栏 + 标签切换。
- a11y 全量：键盘全流程（AC-12）、焦点环可见、`reduced-motion` 归零、图表文字替代。

## 九、阶段与验收

| 阶段 | 内容 | 验收 |
|---|---|---|
| R0 | 令牌 + bento 原语 + 状态补齐 | 对比度脚本双主题 ≥4.5:1；`pnpm run typecheck`、`pnpm test` 全绿 |
| R1 | 工作台：hero + 时间轴 + 字段异构 bento + 诊断 dock | AC-1/3/12/13 复验；1440/1024/390 三档截图 |
| R2 | 库 | 行式 bento、排序过滤可用、空态三行内 |
| R3 | 评估 | AC-6 复验；无评委模型路径不误显示 0 分 |
| R4 | 模板 + 设置 + 全局 chrome | AC-11 复验（DevTools 无密钥命中） |
| R5 | 深色 + 响应式 + a11y | NFR-7/8 验证；三档截图含深色 |

执行纪律：

- 每阶段一个独立 diff，验收通过再进下一阶段。
- 跑测试前停掉 3100 服务（SQLite 共用）。
- DESIGN.md 第二节令牌表与第八节流程随 R0 同步更新。
- 每阶段完成做 1440/1024/390 截图归档（`docs/assets/`）。

## 十、风险

| 风险 | 对策 |
|---|---|
| 字段异构后编辑交互复杂化 | 每种形态聚焦态仍走统一 textarea/表格编辑，操作条常驻规则一致 |
| 诊断 dock 降低即时性 | ⌘J 快捷键 + 时间轴 error 徽标 + 修复后 toast 反馈 |
| Cormorant 加载失败 | Georgia 回退，视觉降级不阻塞 |
| bento 网格在窄屏塌陷 | <1280 单列堆叠已进 R5 验收 |
| 时间轴与流式生成节奏冲突 | 生成中当前阶段块骨架化（已有 rise 动效复用），不改字段流式逻辑 |
